# COCO 2017 generic subset (Li-Stick v0.3-combined)

Official source: http://images.cocodataset.org/

- Dataset: COCO 2017
- License: annotations CC BY 4.0; images Flickr (per-image licenses)
- Date accessed: 2026-08-18
- Images: 830
- Annotations: 4250
- Filtering: Official instances_train2017.json; non-crowd boxes; whole-image sample of chair images until ~2000 chair instances (seed 42). Other selected generic boxes on those images are kept.

## Selected classes

- person: 1692
- bicycle: 130
- car: 214
- motorcycle: 115
- bus: 35
- truck: 64
- chair: 2000

Do not treat this directory as the full COCO dataset. Custom Li-Stick hazards
are unlabeled here.

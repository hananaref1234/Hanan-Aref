# Li-Stick AI — Hanan Aref

Integrated development repository combining original Li-Stick AI research code and newer safety-fusion / dataset-preparation work.

**Status:** development prototype, not a certified mobility aid. No new trained checkpoint or accuracy claims until evaluation.

Source baseline: https://github.com/cezarkhatib/li_stick_ai

Original project code is preserved under `legacy/`. Enhanced version files are in `li_stick_next/`, `training_v04/`, and `ui/`.

Dataset images, trained weights and device firmware are not supplied in either source tree. See `docs/DATASET_REQUEST.md` for the assets required from the team.
